## GitHub Pagesへの公開方法
1. このZIPを解凍します。
2. https://github.com/ytakedaworks-bit/araki-kenchiku にアクセスします。
3. リポジトリのトップ階層にある `index.html` と `images` フォルダを、解凍した同名のファイル・フォルダで更新します。
4. 変更をCommitすると、GitHub Pagesのサイトに反映されます。
5. https://ytakedaworks-bit.github.io/araki-kenchiku/ で反映を確認してください。

※ZIPをそのままGitHubに置くのではなく、解凍した中身をアップロードしてください。
※既存の `images` フォルダ内に別の画像がある場合は削除せず、同名ファイルだけ上書きしてください。
※現在のInstagramリンクは以前のページのものを引き継いでいます。実際のアカウントと合っているか公開前に確認してください。
